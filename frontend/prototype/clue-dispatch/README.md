## 打开方式

1. 进入本目录：
   ```bash
   cd frontend/prototype/clue-dispatch
   ```
2. （推荐）起本地静态服务后用浏览器打开，便于天地图瓦片按域名策略加载：
   ```bash
   python3 -m http.server 8765
   ```
   浏览器访问：`http://127.0.0.1:8765/`
3. 也可直接双击 `index.html`（`file://`）。若天地图拒瓦片，界面其余流程仍可点；地图区会提示配置 key。

## 本原型要回答什么

对照 #191 Question：

1. 登记表单：公共＋来源＋类型三层；一条线索一个法域；不记管辖机关与管辖连接点；缺件提示（#198）；几何（土地／矿产＝面，测绘／规划＝点）；来源按 #24。
2. 疑似重复与「已知晓」：60% 按较小块、只比未结案；默认不派；点「已知晓」可派并留痕；「3 群众举报」及其下级只能派；匿名不得反暴露。
3. 自动核查（仅土地／矿产）：进行中／完成／没跑成；重跑提示挂到跑成；测绘／规划无此块；无「跳过」；不因核查结果拦分派；产出只有报告＋分析图。
4. 分派与捞回：选承办机构／人；管辖在分派环节（#187）；不派存放处；捞回入口与理由留痕；旧线索结案逐条提醒。
