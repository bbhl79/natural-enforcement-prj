## 打开方式

1. 进入本目录：
   ```bash
   cd frontend/prototype/clue-dispatch
   ```
2. 起本地静态服务后用浏览器打开，便于天地图瓦片按域名策略加载：
   ```bash
   python3 -m http.server 8899
   ```
   浏览器访问：`http://127.0.0.1:8899/`
3. 也可直接双击 `index.html`（`file://`）。若天地图拒瓦片，界面其余流程仍可正常交互；地图区会提示配置本地 key。

## 核心交互设计规范（严格执行三条交互纪律）

1. **主画布承载核心业务**：
   - 顶栏一级主菜单（五总入口）仍在；统一工作台**不再**用侧栏二级；主区为待办统一清单，经「录入线索」进入登记表单。

## 前端交互设计「四问准则」

| 检验维度 | 落点 | 结论 |
| :--- | :--- | :--- |
| **1. 是否顺畅？** | 工作台待办 LIST＋录入线索；登记页一进完整表单（R1），不甩空文案 | **达标** |
