# 统一工作台与线索中心 · 前端交互与界面原型

单页自包含 HTML 原型（`index.html`）。只做交互与界面原型设计，不进生产代码。按 #207 协议修正（2026-10-24）：移送只指向自然资源部门以外的机关，系统内不属本级管辖的线索报请上级指定管辖；重合度显示「占本线索 x.x%／占对方 y.y%」；文件只收 GeoJSON；附件不收视频；工作台计数为真实计数；实名默认脱敏，点「查看实名」才显示明文并留痕。

## 打开方式

1. 进入本目录：
   ```bash
   cd frontend/prototype/clue-dispatch
   ```
2. 起本地静态服务后用浏览器打开，便于天地图瓦片按域名策略加载：
   ```bash
   python3 -m http.server 8899
   ```
   浏览器访问：`http://127.0.0.1:8899/`
3. 也可直接双击 `index.html`（`file://`）。若天地图拒瓦片，界面其余流程仍可正常交互；地图区会提示配置本地 key。

## 核心交互设计规范（严格执行三条交互纪律）

1. **主画布 100% 全宽承载核心业务**：
   - 采用**两级菜单导航**（见下节）：顶栏一级主菜单 + 侧栏二级菜单；右侧主画布 **100% 全宽** 展示工作台向导或线索中心列表。
   - **取消右侧常驻走查/调试栏**：演示辅助与场景走查默认收起在顶部工具条右侧「演示辅助（默认收起） ▼」小按钮中，点击才浮出面板，支持一键收起或按 `Esc` 关闭。
2. **标准 Master-Detail 右侧滑出详情抽屉（Slide-over Drawer）+ 4 个水平分页签**：
   - 在「线索中心」点击任意线索行或「查看详情 / 补齐缺件」按钮，从右侧滑出侧边详情抽屉（不打断主列表上下文，支持点击遮罩、「✕ 关闭抽屉」或按 `Esc` 关闭）。
   - 抽屉内部采用 **4 个水平分页签** 聚焦单任务，摒弃四象限平铺：
     - **基本信息与要件**：展示公共要件、来源要件、初步涉嫌违法类型与举报人对称脱敏保护，并提供**类型层缺件清单与在线补齐表单**（支持单项「保存补齐」与「一键全部保存补齐」，补齐后缺件实时清零并记入留痕）。
     - **内业核查**：展示土地类、矿产类线索的内业核查状态、《内业核查报告》摘要与《空间套合分析图》预览；没跑成时常驻重跑提示并提供「重跑内业核查」按钮（录入人、本机构内勤、承办人可点）；测绘地理信息类、国土空间规划类点状线索显示不设内业核查说明。
     - **疑似重复比对**：按「与哪条线索重复」（既有线索编号、流水号、标题与线索来源、空间位置、面积与双方各自重合度（占本线索 x.x%／占对方 y.y%）、双图斑叠加对比弹窗）与「与谁重复」（涉嫌违法当事人、承办机构与状态、举报人对称脱敏有限信息视图）上下分块清晰呈现。
     - **流转与留痕**：展示当前承办机构、主办人/协办人、角色权限操作入口，以及按时间倒序排列的不可改写留痕记录。
3. **界面文案 100% 遵循 `GLOSSARY.md` 标准业务术语**：
   - 界面零工程票号、零「区块字母」符号；统一使用 `录入要件`、`内业核查`、`核查结果（核查报告、分析图）`、`初步涉嫌违法类型`、`涉嫌违法当事人`、`疑似重复`、`撤回不派`、`留痕` 等标准业务词汇。

## 两级菜单导航（2026-10-24 09:59 五总入口）

相对 09:34「五项环节切分」顶栏，本轮改为 **五总入口**：顶栏与系统标题平齐；侧栏随一级切换；综合查询不做独立一级。

### 顶栏一级主菜单（五总入口）

同一顶栏横排，由 `ui.primary` 驱动选中态（`workbench`｜`center`｜`case`｜`supervise`｜`admin`；已去掉旧的 `field` 等环节名主键）：

| 一级项 | `ui.primary` | 说明 |
| :--- | :--- | :--- |
| 统一工作台 | `workbench` | 侧栏：待办看板 + 线索录入三环节 |
| 线索中心 | `center` | 侧栏：全部 / 待分派 / 不派 / 结案提醒 |
| 案件中心 | `case` | 侧栏二级为规划中项（见下） |
| 统筹督导 | `supervise` | 侧栏二级为规划中项（含卷宗评查） |
| 系统管理 | `admin` | **有权限才显示**；无权限时**隐藏**该一级（不做成进页说明） |

演示：身份切换区提供「有系统管理权限」开关；默认演示账号关闭则隐藏「系统管理」。

### 综合查询（全局搜，非独立一级）

一期不做独立一级。顶栏右侧常显「综合查询」搜索框＋按钮，**任何人可用**（切换演示身份也不隐藏）。提交后进入线索中心并按关键词过滤。

### 侧栏二级菜单（随一级切换）

- **统一工作台**：待办看板（滚到/聚焦看板，`ui.wsSection='board'`）；① 线索录入、② 内业核查、③ 分派决定（进对应 step 并打开录入流）。
- **线索中心**：全部线索｜待分派 / 已分派｜不派线索（可撤回不派）｜旧线索结案提醒（对应 `ui.tab`: `all` / `assign` / `held` / `remind`）。
- **案件中心**：「现场核查与立案呈批」「案件查办与审理」（标「规划中」）；点后侧栏选中＋主区提示规划中，不进真实业务。
- **统筹督导**：「执法监督与卷宗评查」（标「规划中」，**明确含卷宗评查，勿进案件中心**）；点后提示规划中。
- **系统管理**（仅有权限可见）：账号与权限｜机构与人员｜字典与配置（规划中占位）。

一级与二级联动：点顶栏「线索中心」→ `ui.primary='center'`、`ui.page='center'`；点「统一工作台」同理。旧顶栏环节名（如「现场核查与立案呈批」）不再作一级，仅出现在案件中心 / 统筹督导二级。

相关设计索引：统一工作台壳与三环节导航、线索中心统一归集与查询。

## 前端交互设计「四问准则」逐条检验结论

| 检验维度 | 界面交互设计与落点验证 | 检验结论 |
| :--- | :--- | :--- |
| **1. 用户使用时是否顺畅？** | 主画布 100% 全宽无遮挡；统一工作台待办卡片一键直达对应步骤或线索中心页签；线索中心 6 维下拉筛选即时联动；点击列表行滑出右侧详情抽屉，在「基本信息与要件」页签内直接补齐缺件、在「内业核查」页签内直接重跑，无需跨页反复跳转。 | **达标（通过）** |
| **2. 是否符合用户的使用直觉逻辑？** | 顶栏五总入口与系统标题平齐（统一工作台｜线索中心｜案件中心｜统筹督导｜系统管理）；侧栏随一级切换为二级菜单；新线索按「① 线索录入 → ② 内业核查 → ③ 分派决定」三步推进（点状线索保存后直达分派决定）；列表与详情采用标准「左表右抽屉 + 4 个水平分页签」结构，每次聚焦一件事。 | **达标（通过）** |
| **3. 是否能够引导用户依法依规完成业务？** | 公共层与来源层必填项守住录入门槛，类型层缺件弹窗确认后可保存并常驻详情跟进补齐；疑似重复默认「不派」、点「已知晓，仍要派出」强制留痕；群众举报类强制必派；撤回不派强制勾选 4 项常用原因＋必填补充说明；举报人实名信息双向对称脱敏，有权人须主动点「查看实名」才见明文，并记入留痕。 | **达标（通过）** |
| **4. 是否有利于不同职责的用户间协作？** | 同一套工作台与线索中心支撑一线执法（内勤/主办人/协办人）、区分局/所领导与业务经办、市执法监督处/区执法科三类角色协同；录入人、本机构内勤、承办人可接力补齐缺件与重跑内业核查；既有线索结案触发逐条提醒供有权人员撤回不派或知悉归档；监督角色严格只读并标明职责边界。 | **达标（通过）** |
