## 打开方式

1. 进入本目录：
   ```bash
   cd frontend/prototype/clue-dispatch
   ```
2. （推荐）起本地静态服务后用浏览器打开，便于天地图瓦片按域名策略加载：
   ```bash
   python3 -m http.server 8765
   ```
   浏览器访问：`http://127.0.0.1:8765/`
3. 也可直接双击 `index.html`（`file://`）。若天地图拒瓦片，界面其余流程仍可点；地图区会提示配置 key。

## 本原型要回答什么

对照 #191 Question、#198 缺件决议通知及 **Lei Hu 2026-10-23 拍板（经狂人转达）的 7 项口径**：

1. **登记表单**：公共＋来源＋类型三层叠加；一条线索一个法域；不记管辖机关与管辖连接点；缺件提示（#198：类型层必填缺失标必填，保存时弹窗列缺项确认后可存，缺件清单落库并在详情常驻、补齐后消失；列表／分派页露出开关供直观对比，露出时只作蓝灰提示、非警告、不拦分派）；几何（土地／矿产＝面，测绘／规划＝点）；来源按 #24（卫片归主动发现）；违法类型编码与名称统一对齐已合入的 #203《违法类型编码表（定稿）》（`docs/research/violation-type-codes.md`）。
2. **疑似重复与「已知晓」**：
   - **面状 vs 点状**（Lei Hu 2026-10-23 拍板）：空间「60% 重合（按较小块算）」仅适用于**面状线索（土地类、矿产类）**，只比未结案线索（不予立案、移送算结案）；**点状线索（测绘地理信息类、国土空间规划类）**无空间 60% 重合概念、系统不作空间重合判定，流转到后续核查阶段由人工判断。
   - **60% 重合度参数配置**（Lei Hu 2026-10-23 拍板）：上线初始版本写定 60%，配置项归管理台第二期。
   - **提示时机与默认不派**（Lei Hu 2026-10-23 拍板）：第 1 步「录入」保存／绘制图斑后即算出疑似重复，在进入「分派」决定派／不派时集中展示；默认不派，录入人点「已知晓」继续派并留痕；「3 群众举报」及其下级（含 301–306）必派，仍展示重合信息供参考。
   - **匿名与实名关联展示（对称保护）**（Lei Hu 2026-10-23 拍板）：无论主线索还是关联线索，举报人实名信息均按查看人权限脱敏／有限视图展示（任一方涉匿名时时间只到月、位置只到区，不显示反映人身份与联系方式、原始材料、精确几何、录入人），防止通过关联线索反向暴露实名举报人。
3. **自动核查**（#111 L2 ＋ Lei Hu 2026-10-23 拍板）：仅土地／矿产；进行中／已完成／没跑成；**测绘地理信息、国土空间规划不设自动核查**，保存后步骤条只有「线索录入 → 分派决定」；**无「跳过」按钮**；**不因核查结果拦分派**；产出只有核查报告＋分析图。没跑成时**后台先自动重试（最多 3 次）**，仍未成功则挂重跑提示直到跑成，**录入人、本单位内勤、承办人**均可手动点「重跑自动核查」。
4. **分派与捞回**（#187 ＋ #25 ＋ Lei Hu 2026-10-23 拍板）：录入人在步骤③决定派或不派。承办机构→主办／协办在「线索中心 · 待分派 / 已分派」。管辖在这一步判定（含测绘兜底、管辖移送示意）。不派线索在「不派线索（可捞回再派）」。捞回权限归**录入人本人、录入单位内勤、旧线索承办单位内勤**（监督不能捞回）。捞回须勾选 **4 项常用原因中的至少 1 项（同一地点不同违法、新增情况、原线索核查不属实需重派、误判重复）并填写补充说明**。旧线索结案时，在「旧线索结案提醒」逐条处理（直接捞回重派，或知悉归档），不自动派、不自动关。

## 导航

左侧只有两项：

1. **统一工作台**：待办数量，以及「＋ 线索录入」。土地、矿产的步骤条是 ① 线索录入 → ② 自动核查 → ③ 分派决定。测绘地理信息、国土空间规划没有自动核查，步骤条是 ① 线索录入 → ② 分派决定。可点步骤条，也可点「上一步 / 下一步」。
2. **线索中心**四个页签：全部线索（违法大类、来源、状态、关键字）、待分派 / 已分派、不派线索（可捞回再派）、旧线索结案提醒。

疑似重复在步骤②和步骤③分两块展示：**与哪条线索重复**（编号、流水号、事由、位置、来源、登记时间、面积、重合亩数与较小图斑占比，以及图斑对比）、**与谁重复**（当事人、辖区与主办人、当前阶段、按权限脱敏的举报人）。

录入表单里，地类、是否占用永久基本农田、矿种、开采方式、采矿权、地图成果类型、涉密等级、规划分区、规划许可、违法主体类型、是否实名举报、下发／移送级别、紧急程度、卫片批次等用下拉、单选或复选。地址叙述、事实概述、文号、姓名、电话、面积仍用文本或数字。

右侧「交互引导场景」6 个场景按上述导航逐步点；顶部可切换身份。

## 已定口径汇总（7 项拍板口径全部落地）

出处：Lei Hu 2026-10-23 拍板，经狂人转达。

1. **点状 vs 面状重合**：空间 60% 重合仅适用于面状线索（土地、矿产）；点状线索（测绘、规划）不做空间重合判定，转后续核查阶段人工判断。
2. **60% 参数配置**：上线初始版本写定 60%，配置项归管理台第二期。
3. **编码与名称统一**：违法类型以已合入的 #203《违法类型编码表（定稿）》（`docs/research/violation-type-codes.md`）为准。本页代表类型包括 `land_occupy_without_approval`（未经批准或者采取欺骗手段骗取批准，违法占用土地）、`land_farmland_permanent`（破坏永久基本农田行为）、`mineral_mine_without_license`（无证采矿）、`mineral_mine_overstep`（越界采矿）、`survey_internet_map_service_unapproved`（互联网地图服务未经依法审核批准）、`survey_qualification_none`（未取得测绘资质证书，擅自从事测绘活动）、`planning_build_without_permit`（未取得建设工程规划许可证或者未按照建设工程规划许可证的规定进行建设）。线索来源仍用 #24 编码表。
4. **自动核查没跑成重跑**：后台先自动重试（最多 3 次）；录入人、本单位内勤、承办人均可手动点「重跑自动核查」。
5. **捞回「不派」线索理由**：4 项常用原因勾选（①同一地点不同违法、②新增情况、③原线索核查不属实需重派、④误判重复）＋必填补充说明。
6. **匿名与实名关联展示**：对称保护——无论主线索还是关联线索，举报人实名信息均按查看人权限脱敏／有限视图展示，防止反向暴露。
7. **疑似重复提示时机**：第 1 步「录入」保存／绘制图斑后即算出疑似重复，在进入「分派」决定派／不派时集中展示，由录入人点「已知晓」继续派或维持默认不派（投诉／举报必派）。
