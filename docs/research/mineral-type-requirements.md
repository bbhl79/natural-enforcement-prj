**一（三）勘查类注意事项**（印刷页 95，4 条）：

1. 违法勘查的行政处罚首先适用责令停止无证勘查违法行为。再根据情节和违法行为后果决定是否给予其他行政处罚。
2. 处罚权限依照国土资发〔2003〕17 号《市（地）县（市）级国土资源主管部门矿产资源监督管理暂行办法》第六条执行（市县级处罚无证勘查、越界勘查）。**该文件已废止**（见 §5.1）。
3. 情节严重需要吊销勘查许可证的，处罚机关在作出其他处罚决定的同时向原发证机关提出建议，由原发证机关决定。
4. 采矿权人在其矿区范围进行生产性勘查，不属于无证勘查。

**二（五）开采类注意事项**（印刷页 104–105，7 条）：

1. 擅自改变开采矿种（共生、伴生除外）或者探矿权人持勘查许可证采矿的，按照无证开采予以处罚。
2. 破坏性采矿的处罚依照旧矿法第四十五条，由省级地质矿产主管部门决定。**旧矿法第四十五条已随 2024 修订失去效力**（见 §5.2）。
3. 处罚权限依照国土资发〔2003〕17 号第七条执行。**该文件已废止**。
4. 越界开采但未采出矿产品的，处罚是责令退回其合法矿区范围。**该口径与新矿法第 64 条不一致**（见 §5.2）。
5. 井巷工程在批准的矿区范围外且未实施开采的，不属于越界开采。
6. 建设单位在工程建设项目批准占地范围内，因工程需要动用或采挖砂、石、土用于本工程建设，不认定为无证采矿。在上述范围内采挖砂、石、土擅自进行销售或用于其他工程建设项目的，认定为无证采矿。
7. 情节严重需要吊销采矿许可证的，处罚机关向原发证机关提出建议，由原发证机关决定。

**三（五）转让类注意事项**（印刷页 109–110，6 条）：

1. 违法转让矿业权行为不能仅以签订转让合同或者协议、支付转让价款予以认定。还应当确认受让方是否实际接收、控制矿山。
2. 「买卖、出租或者以其他形式转让矿产资源」的定义：农村集体经济组织、其他单位或者个人，允许他人开采依附在自己拥有所有权或使用权的土地上或地表下的矿产资源，从中牟利。此种行为与违法转让探矿权、采矿权有区别。处罚依照国土资发〔2003〕17 号第七条第（三）项执行。**该文件已废止**。
3. 矿山企业单纯将采掘工程对外承包，不属于采矿权转让。
4. 处罚权限依照国土资发〔2003〕17 号第八条执行。**该文件已废止**。
5. 依照《国务院关于全面整顿和规范矿产资源开发秩序的通知》（国发〔2005〕28 号），非法转让探矿权采矿权的受让方，按无证勘查开采予以处罚。
6. 情节严重需要吊销许可证的，处罚机关向原发证机关提出建议，由原发证机关决定。

**四（三）审批发证类注意事项**（印刷页 114，3 条）：

1. 对违法批准勘查开采矿产资源的处理，属于行政处理，不属于行政处罚。
2. 涉嫌犯罪的，应当依法移送司法机关追究刑事责任。
3. 涉及矿业权审批权限的违法定性，按照《自然资源部关于推进矿产资源管理改革若干事项的意见（试行）》执行。**该文件即自然资规〔2019〕7 号，已被自然资规〔2023〕6 号废止**；6 号文核心内容已上升为实施条例（见 §5.1）。

## 3. 逐行为类型录入要件

### 3.1 设计原则

1. **要件是登记环节的最低呈现集，不是办案证据清单**（#24、GLOSSARY「录入要件」）。3.2.3.2 的证据项多数属核查、调查阶段产物。登记那一刻该有或该提示的才设要件。其余不呈现。
2. **六属性照 #24**：要件键、呈现、必填性、必填时机（录入时／核查前补齐／只提示）、缺件后果（阻断／警告／提示）、依据（条号＋【法/业】）。
3. **必填时机与缺件后果的搭配**：必填（录入时）→ 录入缺失即阻断。必填（核查前补齐）→ 录入时缺失给警告，立案前的齐备把关由 #30 校验规则按要件键引用（#24 第三节：「整体能否推进」归校验规则）。选填（只提示）→ 提示。「核查前补齐＋警告」的搭配沿用 #24 来源层 `clue.campaign_no`、`clue.opinion_ref` 先例。
4. **宁缺毋滥**：公共层能承载的不重复设。位置（面）→ `clue.location`（契约 §3.7:100，矿产＝面，业务口径，#24 第十二节）。协议、凭证、账目等实体材料 → `clue.materials`（公共层选填）。行为时间、经过 → `clue.narrative`。来源层已有的（交办文号、移送函编号等）不重复设。
5. **要件键前缀定为 `clue.mineral.*`**（#24 授权本票定案）。理由：公共层与来源层是跨法域共用键，平铺在 `clue.*`。类型键为矿产法域专有。加法域段可防四个法域的类型键冲突（土地、测绘、规划同样会有 situation、license 类键名）。前缀也支持表单按组渲染与按法域统计。校验规则仍按单键引用，不受前缀影响。
6. **类型要件取并集**（#24 第七节：初步涉嫌违法类型可空、多值、逐条选）。同一要件键在多个所选类型下必填性不同时，**建议按最严者呈现与判定**。并集合并语义 #24 未规定，此条是建议，实现时由 #30 定案。
7. **证照项逐行为定，不一刀切**（票面约束）：越界勘查、越界采矿、破坏性采矿、擅自滚动勘探开发类、转让矿业权类的主体是持证人，设许可证号项。纯无证类（无证采矿）不设许可证号项。
8. **登记时记当时必填清单**（#24 第九节、ADR 0018）。本稿只出当前版。

## 4. 地质灾害、矿山环境：查证事实与建议结论

### 4.1 已查证事实

1. **附录 B 没有地质灾害、矿山环境条目。** 附录 B 全文（印刷页 93–114）只有四个大类、11 项具体违法行为。附录 A、C、D 也无此类条目（底稿 §5 骨架核对）。
2. **规程 3.2.3.2 末段的「参照执行」是证据收集条款，不是类型条款。** 原文：「地质灾害、矿山环境等违法案件参照上述证据范围要求收集相关证据材料。」它只回答「这类案件收什么证据」，不回答「这类案件是什么违法类型」。规程附录 B 未因此增加条目。
3. **《地质灾害防治条例》（国务院令第 394 号）给自然资源主管部门（原国土资源主管部门）设了独立罚则**：第 41 条（建设单位未做地质灾害危险性评估、配套治理工程未验收即投入使用：责令限期改正，逾期不改责令停止生产施工或使用，处 10–50 万元罚款）；第 42 条（对人为活动引发的地质灾害不予治理：责令限期治理＋代履行＋10–50 万元罚款）；第 43 条（地质灾害危险区内爆破、削坡、工程建设等：责令停止，单位 5–20 万元、个人 1–5 万元罚款）；第 44 条（评估、治理工程单位弄虚作假、无资质承揽等：罚款、停业整顿、降低或吊销资质，处罚主体为「国土资源主管部门或者其他部门依据职责」）。第 41–43 条处罚主体均为县级以上（地方）人民政府国土资源主管部门，机构改革后由自然资源主管部门承接。地方权责清单（湖南政务服务网）已核对到上述处罚事项挂在自然资源部门名下。
4. **《矿山地质环境保护规定》（国土资源部令第 44 号，经三次修正）已被废止。** 废止依据：《自然资源部关于第七批废止的部门规章的决定》（自然资源部令第 20 号，2026-01-01 公布施行）。同批废止《建设用地审查报批管理办法》。
5. **矿山环境类现行罚则锚点**：矿法第 69 条（勘查活动结束后未及时清理、未恢复地表植被：5 万元以下／5–10 万元罚款＋代为清理恢复）；矿法第 71 条（采矿权人不履行矿区生态修复义务或未按批准方案修复：修复费用 2 倍以下／2–5 倍罚款＋代为修复）；矿法第 70 条、实施条例第 68 条（未汇交地质资料、未报送储量报告或闭坑地质报告：2–10 万元／10–50 万元罚款）；《土地复垦条例》（国务院令第 592 号）第 37–43 条（复垦费未列支、表土未剥离、未报告、拒缴复垦费、拒绝阻碍检查等，处罚主体含国土资源主管部门）。实施条例第 50 条第 4 款：已编制矿区生态修复方案的，不再编制土地复垦方案。
6. **#35 决策 1**：法域枚举严格取处罚办法第 2、55 条四类封闭清单。新增法域要部里出新的规程与附录。**#35 决策 2**：违法类型两级结构直接采用规程附录，实体对齐具体违法行为级。

### 4.2 建议结论（本节是建议，不是已查证事实的延伸）

**建议：地质灾害、矿山环境不单列为违法类型。** 理由：

1. 类型清单的源头是规程附录（#35 决策 2）。附录 B 无此两类条目。单列即系统自造类型，偏离对齐原则。
2. 规程 3.2.3.2 的「参照执行」只授权证据收集口径，不构成类型授权（§4.1 事实 2）。
3. 处罚办法第 2 条的「等自然资源管理法律法规」已在部级规程层面收敛为四类（#35 决策 1）。地质灾害防治条例、土地复垦条例属自然资源管理法规，其案件仍在四类法域框架内办理，缺口只在「类型」层，不在「法域」层。

**这类线索的登记路径建议**：

1. 法域选「矿产」。依据：规程 3.2.3.2 把地质灾害、矿山环境案件归入矿产违法案件证据框架【业】。此归属无明文法条，是业务口径，需主会话确认。
2. 初步涉嫌违法类型留空。公共层 `clue.initial_types` 本就可空（#24 第五节说明 3）。类型留空时只有公共层与来源层要件，登记不受阻。
3. 反映的情况（`clue.narrative`）写明灾害或环境事实。用标签（如「地质灾害」「矿山环境」）辅助筛选。标签库是运行期业务表（#24 第八节），不受附录约束。
4. 行为同时符合附录 B 条目的，照常选类型。例：无证采矿同时破坏地质环境的，选「无证采矿」。破坏性采矿造成资源破坏的，选「破坏性采矿」。
5. 核查、立案后，案由按规程 2.5 拼装（「可参照」附录，不是「必须取自」附录）。依据条款直接引具体条文：地质灾害防治条例第 41–44 条、矿法第 69／71 条等。依据条款是版本化对象（#35 决策 5、ADR 0016），可承载不挂附录 B 条目的条文——此点需在依据条款库的票里确认承载形状。
6. 若业务方将来要求这两类有类型挂载点，正路是推动部级附录修订，或依规程 1.10 由地方实施细则授权后扩充版本化清单。本系统不自造。

### 5.3 对系统的直接影响

1. **类型清单（11 项）不变。** 附录 B 现行未修改。变的是依据条款。#35 决策 5 的版本化对象（违法类型清单＋依据条款）正好承载：清单版本不动，依据条款版本更新。
2. **本稿要件「依据」栏双引。** 附录 B 项号【业】＋现行法条【法】。登记要件呈现的是业务口径，法定锚点随依据条款版本走。
3. **从旧兼从轻双时点比对**（行政处罚法第 37 条）在矿产类是高频场景：旧矿法第 39/40/44 条与新矿法第 63/64/68 条罚款基数、幅度全部不同（违法所得百分比 → 矿产品市场价值倍数或定额）。该机制归 #35 决策 5 的双快照票，不在本清单，但矿产是其第一个验收法域。
4. **规程与处罚办法无矿产管辖冲突。** 矿产案件由不动产所在地县级机关管辖，两文件一致（底稿 §2.1）。
