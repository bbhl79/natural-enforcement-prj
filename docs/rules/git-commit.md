# Git 提交规范（AI 强制约束）

统一项目 Git 提交信息格式，确保提交历史清晰、可追溯、可检索。

## 提交信息格式

经用户明确要求提交、或项目已配置允许自动提交时，使用以下原子化提交信息格式：

```
<type>:<年-月-日-时-分>||<简体中文提交信息>
```

## type 取值

| type | 说明 |
|---|---|
| chore | 日常维护、配置调整 |
| feat | 新功能 |
| docs | 文档变更 |
| test | 测试相关 |
| fix | 缺陷修复 |
| hotfix | 紧急修复 |

## 示例

```
feat:2026-06-07-09-30||添加用户登录接口
fix:2026-06-07-10-15||修复健康检查端点响应格式
docs:2026-06-07-11-00||更新镜像源策略文档
```


## 提交前检查

提交前运行 `git diff --cached --check`，检查本次暂存改动的空白错误。

## 原子化原则

- 每次提交应聚焦一个逻辑变更，避免混合不相关的改动。
- 出现错误时优先上报、暂停自动提交与推送，不得为“赶进度”把错误掩盖在一次 fix 提交里。

## 约束

- 本规则为项目硬性规范，AI 代理及项目成员必须遵守。
- 未经用户明确要求提交时，AI 只准备变更和建议提交信息，不执行 `git commit` 或 `git push`。
- 如需修订，须先说明原因并取得用户确认。
