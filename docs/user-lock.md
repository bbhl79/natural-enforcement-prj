## L1 听证申请期

- **编号**：L1
- **原文**：
  > 听证申请期＝可配置，默认五个工作日（改配须绑依据文号／条号、仅新案、禁短于依据下限）。查处写死五日废止，以 D3 为准。
- **白话说明**：听证申请期可以改，默认五个工作日。改时要写明依据的文号或条号。改动只对新案生效。不能短于依据规定的下限。原先写死五日的做法作废。

- **断言编号**：`USER-LOCK-L1`

## L3 应听证不得自免

- **编号**：L3
- **原文**：
  > 应听证命中不得主办自免「不适用听证」；关旁路；默认听证告知／申请期；期满未申请＝视为放弃。
- **白话说明**：命中应听证情形时，主办不能自免。主办不能勾选「不适用听证」。系统不留绕过的入口。默认发出听证告知，并给出申请期。期满没有申请，视为放弃。
- **出处**：Lei Hu 2026-10-02 拍板，2026-10-17 19:44 复确认。
- **断言编号**：`USER-LOCK-L3`
