# 0008 运行参数与密钥分轨供给

Status: accepted（2026-10-13）

管理台容易被理解成可以改一切配置。密钥读出来就等于拿走访问能力，运行参数改完必须重启，配置类对象则要走批准后才生效。2026-10-13 定案：三类分开供给。生产密钥由部署环境注入容器。开发夹具和天地图的开发测试 token 写在 `infra/runtime.env`。天地图的生产 token 由部署环境覆盖同一个变量。运行参数与这份清单放在一起，`dev`、compose、CI 只引用它。一期管理台不展示密钥，不编辑运行参数，不提供关断开关，也不展示连通状态。

这样做是为了让密钥不进维护界面，并让同一批参数名只留一处。

细则在 [管理台：运行参数与密钥来源约定](https://github.com/bbhl79/natural-enforcement-prj/issues/80) 的决议。本篇只记为什么这样定。

## Considered Options

- 密钥放进数据库或管理台，供维护人员轮换。否决。读出值就等于拿走访问能力。轮换是部署环境换值后重建容器。
- 运行参数走配置类对象的批准门。否决。改这些值的人是部署者，而且必须重启进程。批准门留给文书模板、校验规则、工作日历、统计指标口径。
- 清单放在 `docs/`。否决。这份清单是给进程读的。
- 源码继续内嵌一套默认值。否决。默认值会和清单各改各的。缺密钥环境变量时进程启动失败。
- 一期不接入天地图。否决。一期要接入天地图。开发测试 token 写入 `infra/runtime.env`。生产 token 由部署环境覆盖。
- 对象存储、队列或天地图断开时，改写案件状态或在管理台提供关断开关。否决。断开只让对应能力失败。案件状态保持原样。一期管理台不提供开关。

## Consequences

- `DATABASE_URL` 与 `REDIS_URL` 由 `dev` 从清单里的分项算出，不在清单里再存一份。`E3_BUCKET` 与 `E3_RUN_ID` 留在 E3 测试脚本。
- localhost 证书由 `dev up` 在仓库外生成。生产证书与私钥由部署环境挂载进 nginx。
- 对象存储不可达时，上传和读取返回明确错误。队列不可达时，本次不入队，同步请求仍成功，健康检查把队列标为失败。天地图不可达或 token 无效时，底图不出现并给出明确失败。案件的读取和写入照常。PostgreSQL 或 nginx 不可用时，进程不对外服务。
- IdP 与可信时间戳的关断留在各自的接入票。IdP 一期不实现，清单里不预置 IdP 密钥。
- 天地图的图层、坐标与调用协议不在本决议。管理图层的数据来源仍在 [广州市自然资源行政执法系统 · 实施路线图](https://github.com/bbhl79/natural-enforcement-prj/issues/9)。
- [认证：IdP／粤政易适配口形状](https://github.com/bbhl79/natural-enforcement-prj/issues/72) 不再另定供给形态。[管理台：界面落点与前端骨架归属](https://github.com/bbhl79/natural-enforcement-prj/issues/79) 的一期界面不含这些入口。
- 术语见 `GLOSSARY.md` 的「密钥」「运行参数」「口令」「配置类对象」。
