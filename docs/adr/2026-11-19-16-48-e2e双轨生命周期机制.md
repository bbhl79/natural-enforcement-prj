# e2e 双轨生命周期机制：探索→复现单向毕业，缺陷记录文件化

- 状态：accepted
- 日期：2026-11-19（2026-11-21 修订：随 #13 原型实证与 #14 Spec-e2e体系 批准）
- 决策记录：[Grilling-e2e生命周期机制设计](https://github.com/bbhl79/natural-enforcement-prj/issues/10)、[Spec-e2e体系](https://github.com/bbhl79/natural-enforcement-prj/issues/21)

## 决策

e2e 体系由**探索轨道**（发现未知缺陷，不进 CI）与**复现轨道**（逐 PR 运行的确定性回归）组成，单向转换：探索→复现可**毕业**，反向禁止。毕业命令是复现轨道用例的**唯一合法写入路径**，由工具与制度双重保障。具体机制：

1. **状态机四站**：`reported`（过门禁、已登记）→ `graduated`（复现用例已入轨）→ `fixed`（修复确认）；`retired` 终态（记录原因、用例移除、缺陷报告永久留档）。不设隔离态。
2. **事实源分层**：每缺陷一个 JSON 文件（入库）是生命周期事实源；目录表达用例归属轨道；测试文件头只放缺陷链接，不复制状态；注册表是派生缓存，不入库，校验器**始终重建**，漂移仅 WARN 不作硬门禁（原型实证"漂移即红"会死锁），完整性锚在入库记录与 git 历史。缺陷记录永不删除。
3. **复现门禁按被测路径分类**：纯函数/无外部状态重放 1 次；依赖外部状态/并发在独立键空间重放 ≥3 次。次数是检查预算不是证明：每次从明确前置状态开始、同一断言同一原因失败（由失败签名比对机器化判定）；并发缺陷保留触发时序。门禁由命令实测回填，非自查申报。量化依据（WebProber 85% 误报）仅作方向性佐证，不作阈值推导。
4. **毕业事务（两段式 + 确认令牌）**：第一段预检→转写→独立配置真跑一次→产出证据摘要与确认令牌，**不落账**；第二段携令牌在 per-worktree 写锁的单一临界区内重验并落账，确认记录入缺陷 JSON。令牌绑定六元组：verify-run 编号 + 证据哈希 + 源码树哈希 + 应用镜像 digest + 执行器镜像 digest + 迁移版本；镜像与迁移标识由起栈时实查写入 run 登记册。**口径：记录被测镜像及其构建来源，用于审计与追溯**，不声称可证明构建内容（可复现构建是后续方向）。未修必须失败 / 已修必须通过，两个方向都须核对证据。工具强制顺序/对应/留痕；"确认者须为人类"是制度约定（CLI 无法鉴别操作者），靠 PR review 与审计追责。任一步失败工作区全量还原；测试与缺陷记录同一 commit。不可机械转写者经草稿区（CI 不收集）补完断言后转正。fixImmediate 旁路：修复 PR 顺带用例，同一命令同一验证，生来绿直接 fixed。
5. **预期失败闭环（失败签名核对）**：毕业未修，用例带预期失败注解且缺陷记录含失败签名（提取自经人确认的毕业证据）。CI 判定权收归判定引擎（本地与 CI 同一判定器）：失败且签名匹配→绿；**基础设施错误**（连接/超时/不健康）→红；**测试定位失败**（元素缺失）→红并标明"需人判断是 UI 改版还是缺陷"；其他签名不符→红；通过→红（触发 confirm-fix）。签名含错误类别+断言标识+关键语义标记，不含完整消息文本。confirm-fix 真跑验证后摘注解转 fixed。
6. **防降级校验**（本地与 CI 同一校验器）：索引一致性（用例↔记录双向锁死）、注解纪律（skip/fixme 全禁、预期失败注解仅限 graduated 且记录含签名）、编号连续无洞、diff 级检查（repro 删除/移动必须伴随退役；**删缺陷记录无条件红**——洗白路径唯有此闸能抓，**CI 必须带基线分支参数**）。v1 不做内容哈希。
7. **缺陷报告 schema**：zod 按引擎判别联合；`DEF-NNNN` 递增号（本地 max+1 取号，撞号 renumber 机械重排，CI 查唯一+连续）；证据只存 URI 不入库，靠零依赖 `replayCommand`（exit 0=复现）长期重建；graduation 元数据含失败签名与确认记录。
8. **复现用例统一收敛**复现轨道，Playwright runner，默认黑盒（API/UI）；仅共享包导出的纯函数允许白盒复现（应用内部逻辑必须走 API）。
9. **回收与钉住**：产物与 run 资源同窗（默认 7 天，实测校准）机会式清理；删除双条件（e2e 专属前缀 + run 登记册记录），宁漏勿误。explore run 默认钉住（环境与产物豁免窗口），发现全部登记或显式放弃才解钉；钉住有上限与到期强制复核，到期不自动删除。
10. **命令面**：顶层 `devenv ci`（与 CI 同构）/ `explore` / `verify`；子命令 `devenv e2e report | graduate | confirm-fix | retire | replay | renumber | defect show|list | runs`；全部 `--json`、退出码枚举化（**总表归工程基座 SPEC**，e2e 登记专用码段）。生命周期 CLI 为纯决策引擎 + op 行协议，devenv 宿主侧原子应用。CI 只经 devenv 调用，靠独立配置 + 目录约定自动生效，毕业不改任何 CI 文件。

## 背景

- 地图硬不变量 3 要求双轨单向由「毕业命令 + 校验工具化、制度化」保障；本 ADR 是该不变量的机制化。
- 约束：AI-Native（1 人 + 多 agent 并发 worktree、机器可解析输出、fail-fast）、devenv 唯一入口、基础设施容器共享 + 数据级隔离、apps 互不依赖（#9）。
- 依据：docs/research/playwright-e2e.md §2–§4、docs/research/exploratory-testing.md §3–§4；#13 原型全流程实证（分支 prototype/e2e-dualtrack，devenv/NOTES-e2e.md）。

## 考虑过的选项

- **中央注册表（入库）为事实源**：多 agent 双写次次冲突、双账本漂移 → 拒绝；每缺陷一文件，注册表退化为派生缓存。
- **注册表漂移即红**：原型实证死锁（失败运行不重写缓存→下次必报漂移→永远红）→ 拒绝；漂移仅 WARN+始终重建。
- **状态写在测试文件头注释**：毕业前文件不存在、注释不可查询 → 拒绝。
- **复现用例按发现层散落各包**：跨 runner/目录校验、撬 apps 边界 → 拒绝；统一收敛。
- **毕业与修复绑定**：毕业被无限推迟 → 拒绝；expected-fail 先行 + fixImmediate。
- **裸 expected-fail（失败即判绿）**：环境故障、元素缺失、断言弱化都判绿，用例不再检查原缺陷却伪装"仍在监控" → 拒绝；失败签名核对。
- **毕业确认单命令旗标**：旗标先于证据填写，顺序不可保证 → 拒绝；两段式+令牌。
- **毕业确认放 PR review**：落账先于确认，事后追认 → 拒绝。
- **令牌只绑源码树哈希**：无 bind 架构下工作区与被测镜像可能不同版本 → 拒绝；六元组绑定实际被测镜像与迁移版本（审计口径）。
- **skip/fixme 承载未修复用例**：腐烂+降级后门 → 拒绝。
- **quarantined 隔离态**：静默降级通道 → 拒绝；偶发失败按新缺陷处理（裁决人/时限/两条快速出口见 SPEC 风险章节）。
- **内容哈希防篡改**：绊倒合法重构 → v1 不做，留迷雾。
- **GitHub issue 号 / ULID 作 ID**：发现时无 issue、人读不友好 → DEF-NNNN + 重排。
- **tag 区分双轨 / 毕业改 CI YAML**：纪律可漏、写点冲突 → 目录+独立配置。
- **run 资源统一一套命名规则**：PG 标识符与 S3 bucket 规则冲突（下划线/连字符/长度），静默截断可撞名 → 拒绝；三套净化规则+截断拼哈希。
- **到期自动删除钉住资源**：未稳定复现发现的取证现场不可重建 → 拒绝；到期强制复核，不自动删。

## 后果

- GLOSSARY.md 术语：探索轨道/复现轨道/毕业/缺陷报告/复现门禁/退役/探索任务书/失败签名/确认令牌/钉住。
- 复现用例内容级弱化是 v1 接受的残余风险，靠 PR review 与探索再发现兜底；真实摩擦出现再启用 codeHash。
- 失败签名是保证链中最新、未经原型验证的一环：验收含原型缺陷（DEF-0001/0002）回放实测，实施后持续观测误判率。
- 复现轨道偶发失败：人类裁决（1 个工作日），retire+重建或新缺陷毕业两条快速出口；阻塞无关 PR 是有意代价，人类不在时阻塞持续是明确接受的结果。
- 探索调度常态化、归因草稿生成器仍留迷雾/backlog；triage 衔接已入 SPEC（过门禁→needs-triage，证据不全→needs-info）。
- 探索引擎 P1–P4 以 backlog issue 常驻（#17–#20），前置完成时必须唤起复查。
