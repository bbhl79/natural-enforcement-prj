# 0019 依据以文件表引用承载

Status: accepted（2026-10-21。Lei Hu 拍板，见 [#195 决议](https://github.com/bbhl79/natural-enforcement-prj/issues/195)）

要件项与违法类型里的「依据」，不再写自由文字。每条依据只写「文件编号 + 条号」，指向文件表。文件表就是 [0016 参照数据随种子只追加写入](0016-参照数据随种子只追加写入.md) 里的依据条款参照数据，以「业务编码 + 版本」为键，只追加。

这样定，是因为原先的【法】／【业】二分标注表达不出位阶差，三类用途不同的依据又并列在同一栏，靠括号备注区分。括号备注不能被静态校验，也不能被前端分组。

## Considered Options

- 依据继续做自由文本。否决。程序读不懂，位阶、用途、失效状态都只能靠人看。
- 每个引用处自带「文件、条号、层级、用途、状态」五个子字段。否决。层级与状态是文件自身的属性。同一份文件被几十处引用，改一次状态要改几十处。
- 处罚、裁量基准、移送处分依据挂在每个要件项上。否决。它们说的是整个违法类型，按要件项重复挂会漂移。

## Consequences

- **两处引用，写法相同。** 要件项的「依据」只表示为什么要呈现这一项，只写文件编号与条号，不带用途。违法类型挂四组依据，每条依据带用途。
- **依据用途四类**：处罚、裁量基准、移送处分、认定标准。用途写在引用处。
- **效力层级九档**：法律、行政法规、司法解释、部门规章、部门规范性文件、省级地方性法规、设区的市地方性法规、地方政府规章、地方政府规范性文件。它只是标签，系统不自动比较高低。取代【法】／【业】标注。
- **效力状态三值**：现行有效、已废止、存疑。存疑指文件未被明文废止，但制定依据已失效，必须附说明与出处。
- **三条可测断言**：
  - 每条处罚依据的层级，都不得是部门规范性文件、地方政府规范性文件、司法解释。
  - 每条依据引用的文件编号，必须存在于文件表。
  - 处罚依据不得引用已废止的文件。引用存疑文件时，前端显示提示。
- **与 0018 的断言无关。** 0018 的「必填集合与缺件判定集合相等」不受影响，依据不在必填集合里。
- **版本冻结归 #42。** 文件表带效力状态，#42 按文件表版本冻结行为时依据。
- **旧草案待改。** #181、#183、#184 的依据栏要改成「文件编号 + 条号」，并入 Map 中「收敛三份草案」一项，等 #197 编码表定稿后一次做完。
- 术语见 `GLOSSARY.md` 的「依据条款」「效力层级」「依据用途」「效力状态」。
