# 0009 角色按职责，案件单环节流转

Status: accepted（2026-10-14）

规格给了六族角色和一张粗动作矩阵。办案时，主办人、协办人要贯穿全案，案件却一环一环交给不同的人处理。2026-10-14 定案：角色按职责分成七个，主办人、协办人不是角色。案件同一时间只处在一个环节。退回交给谁，由作出退回的人指定，系统不自动选路。

这样做是为了让授权和案件流转用同一套人。换一环不改主办人。科长和副局长也不按科室拆成两套角色。

细则在 [认证：角色族×操作码矩阵定案（六族×24 操作码）](https://github.com/bbhl79/natural-enforcement-prj/issues/71) 的决议。本篇只记为什么这样定。

## Considered Options

- 沿用 `viewer` / `clerk` / `supervisor` 四类粗动作，再叠一层操作码。否决。一次操作要过两道门，旧的三行角色也和七个职责对不上。
- 把主办、协办做成角色。否决。同一个人可以在这件案子上主办、在另一件上协办。角色表达不了「这一件案子上的人」。
- 执法科和法治科各设一套审核角色、一套审批角色。否决。差别在任职机构，不在角色名。
- 退回时系统固定回到该链的起点，或只退给上一环。否决。审核人或审批人需要指定接收人。

## Consequences

- 七个角色是内勤、经办、法制审核、行政审核、行政审批、监督、系统管理。合法操作码的名册在 `packages/shield`。允许行在角色—权限表。监督的允许行不参与会改变线索或案件主状态的判断。
- 作出重大执法决定之前必须先完成法制审核。哪些情形算重大，不在本篇点名。
- 术语见 `GLOSSARY.md` 的「经办」「主办人」「法制审核」「行政审核」「行政审批」「退回」。
