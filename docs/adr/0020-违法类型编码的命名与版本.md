# 0020 违法类型编码的命名与版本

Status: accepted（2026-10-21。Lei Hu 拍板，见 [#197 决议](https://github.com/bbhl79/natural-enforcement-prj/issues/197)）

具体违法行为的业务编码取 `<法域短码>_<行为直述>`，法域短码固定四个：`land`、`mineral`、`survey`、`planning`。编码只含小写字母、数字与下划线，不含点号——点号是要件键 `type.<类型编码>.<字段>` 的分段符（见 [0018](0018-录入要件以代码声明承载.md) 与 [#192 决议](https://github.com/bbhl79/natural-enforcement-prj/issues/192)）。每法域的「附录外其他」取 `<法域短码>_other`。编码是 [0016 参照数据随种子只追加写入](0016-参照数据随种子只追加写入.md) 里的业务编码，以「业务编码 + 版本」为键，只追加。

规程附录 A–D 的「一、二、三」大类也发码，作为录入时不可选的分组行；具体违法行为每版存「上级编码」指向它（0016 已定上级显式存编码）。大类码不进要件键。附录序号不进编码，只作为每版的出处属性存。

这样定，是因为四份草案（#181–#184）各自自拟英文短名、互不对齐，而 #192 已定要件键含类型编码段，编码进键后回改代价随声明条数线性增长，命名规则必须一次定死。带法域前缀可防跨法域撞名，与 #182 当年给 `clue.mineral.*` 加法域段的理由相同。

## Considered Options

- 行为直述，不带法域前缀。否决。「占用」「无证」这类词跨法域复用，会撞名。
- 附录序号型不透明码（如 `A-01-02`）。否决。附录改版挪序号后编码指错行；序号另存为出处属性。
- 大类只存中文名、不发码。否决。#199 的呈现分组与统计按大类归并，文字属性在附录改版时漂移；有码则走同一套版本机制。
- 合并或拆分时旧码改含义复用。否决。已引用旧版本的线索语义被篡改；0016 引用即钉版本，要求旧行不动。

## Consequences

- **数量**：附录内 90 码 + 4 个「附录外其他」，共 94 个。不设增补号段（[#194 决议](https://github.com/bbhl79/natural-enforcement-prj/issues/194)）。
- **改版四动作**：新增发新码（版本 1）；废止对旧码追加一版标停用；合并时旧码全部停用、新类型发新码；拆分同理。行为名称因依据换版不再成立的类型不换码，追加一版改名称。
- **编码永不复用**。发过的码永远占位。
- **取代关系只写在停用版的出处文字里**，不建结构化的「被某码取代」字段。统计跨版本合并靠出处人工对照；线索数据量上来后若需要机器可读的取代链，另开票。
- **#182 的 12 个 `clue.mineral.*` 键**随编码表定稿改名为 `type.<类型编码>.*`。
- **回改执行**：四份草案的编码回改、键名改写与 #192/#193/#195 决议的收敛，归 Map 上新开的执行票，一次做完。
- 术语见 `GLOSSARY.md` 的「违法类型编码」。
