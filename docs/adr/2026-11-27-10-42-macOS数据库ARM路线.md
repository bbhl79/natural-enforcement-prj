# macOS 数据库 ARM 路线：kartoza multiarch（arm64 原生）

- 状态：proposed（路线建议已由 Mac 实测支撑；Mac 等待预算与正式支持验收待指挥者核定，归 #78）
- 日期：2026-11-27
- 决策记录：[#53 阶段 0 实验①](https://github.com/bbhl79/natural-enforcement-prj/issues/53)；parent [Spec-工程基座](https://github.com/bbhl79/natural-enforcement-prj/issues/23)
- 证据：[docs/research/macos-arm-evidence/](../research/macos-arm-evidence/README.md) · 调查全文 [macos-arm-db-route.md](../research/macos-arm-db-route.md)

## 决策

macOS Apple Silicon 的 PostGIS 数据库默认走 **候选 B：`kartoza/postgis:18.6-3.6.4`**
（multiarch manifest-list，arm64 原生），以 tag + manifest-list digest 双层 pin；
路线切换机制沿用 `DEVENV_DB_IMAGE` 覆盖，`devenv/images.lock` 的默认值在本票**未改**，
正式登记（tag/digest 与 `images --verify`）归 #63。

候选 A（`postgis/postgis:18-3.6` + amd64 仿真）仅作备选，不设为默认；候选 C（自建
arm64 镜像）不采用。

## 背景

- `postgis/postgis` 全部维护标签 **amd64-only**（2026-11-24 registry 复核 12 个标签）。
- 本机 Podman machine provider 为 **libkrun**，宿主 **未安装 Rosetta 2**；VM 内 binfmt
  注册 `qemu-x86_64`，即 amd64 容器走 qemu 用户态仿真。研究文档原先设想的“Rosetta
  近原生”前提在本机不成立。

## 考虑过的选项

- **A. amd64 仿真（官方镜像零改动）**：拒绝作为默认。实测同负载比 B 慢 25–33 倍
  （ST_DWithin 133.5 ms vs 5.2 ms；GiST 建索引 2545 ms vs 78 ms），启动 19.7 s vs 7.4 s；
  且 amd64-only 镜像在 arm64 宿主直接 `docker pull` 失败，需为 db 服务引入
  `platform: linux/amd64` 类机制（devenv 当前不支持）。
- **B. `kartoza/postgis` multiarch**：建议采用（本 ADR 状态 proposed，待指挥者核定）。arm64 原生，devenv 全链路绿（up 含迁移 56.4 s、
  seed 49.0 s、test 67.5 s、增量重建中位 55 s）。供应链：Kartoza 维护（2014 起，707 stars，
  2026-11 仍更新）、Debian + PGDG **GPG 签名** apt、GitHub Actions 构建、镜像内记录
  `PG_VER_PROD=18.6` / `GIS_VER_PROD=3.6.4` / base digest；以 manifest-list digest
  `sha256:5fa6f8e2…` pin。风险：非 Official Image、镜像 1.84 GB、额外扩展（pgrouting/
  raster/cron/h3 等）、build 脚本 GPL-2.0（仅 dev 使用、不分发）。
- **C. 自建 arm64 镜像**：拒绝。B 已满足；自建需持续跟随 PG/PostGIS 版本与构建/扫描
  流水线。

## 后果

- **收益**：Mac 上空间查询/索引构建恢复原生性能；无需 Rosetta 依赖，也无需平台 pin 机制。
- **代价（如实）**：第三方供应链信任面扩大；镜像体积约为官方 amd64 镜像的 2.6 倍；
  额外扩展增加未使用攻击面；Docker Hub tag 与 git tag 命名不一致，必须锁 digest。
- **未决**：Mac 等待预算待指挥者核定；`images.lock` 未改（#63 登记）；Rosetta 路线未实测；
  macOS 正式全量支持验收归 #78，本 ADR 不声称已支持。
- 实验同时修复了 macOS 兼容缺陷：bash 3.2 全角字符紧邻变量的解析、空数组展开；
  BSD `stat` 与认证离线测试 `flock`/`wc` 可移植性由 PR #87 独立修复（详见证据 README）。
