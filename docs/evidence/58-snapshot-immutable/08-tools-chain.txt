== 反例 b：覆盖 tools:local 标签后 up ==
tools:local 被覆盖指向 workspace 镜像（状态 tools 镜像变悬空）→ up 事件：
{"event":"tools.fresh","imageId":"sha256:9ffac01b5701"}
{"event":"workspace.fresh","imageId":"sha256:5972bc19cfa5"}
{"event":"image.verified","imageId":"sha256:5972bc19cfa5"}
结论：tools.fresh（悬空镜像按 ID 命中，未重建）+ workspace.fresh + 启动核对通过——绑定不受标签覆盖影响

== 实测平台坑（已修）：podman docker image ls 不列出完全无 tag 的悬空镜像 ==
存在性探针不能用 image ls（会把悬空状态镜像误判不存在）；改用 inspect + 引擎探活区分
「镜像不存在（未命中→重建）」与「引擎故障（die 3）」。
